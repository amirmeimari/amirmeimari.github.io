Pick a font.
Apply it everywhere.

StyleShift lets you customize fonts and CSS on any website. Bundle a typeface or upload your own, apply it globally or per site, and it sticks around on every visit.

Get StyleShift — it's free View on GitHub

No font is ever fetched from a remote host. Everything runs locally in your browser.

Everything you need to restyle the web

One popup, per-site memory, and a full CSS editor when you want to go further.

🔤

Font injection

Bundled fonts or your own uploads, applied per site or globally, with an availability indicator on every font.

⚡

One-click site shortcuts

Pre-activated toggles for popular sites like Google, GitHub, Gmail and YouTube — ready to enable in one click.

🖋️

Code font

Pick one monospace font for code blocks across the web; JetBrains Mono ships bundled and ready to go.

🎨

Custom CSS editor

A CodeMirror-powered editor with syntax highlighting, autocomplete, bracket matching and inline error marks.

💾

Persistent, per-hostname

Everything is stored locally and re-applied automatically on page load and navigation — set it once.

🌍

Localized UI

The popup is translated into English, Spanish, Arabic, Chinese and Persian, with more on the way.

Fully offline. Fully yours.

StyleShift has no backend and no servers. Your settings and uploaded fonts never leave your device.

Read the privacy policy
  • Every font is bundled with the extension or uploaded by you — none are fetched remotely.
  • No analytics, no telemetry, no tracking of your browsing history.
  • Settings are stored with chrome.storage.local, keyed only by hostname.
  • Open source under the MIT license — read every line yourself.
