2.0.0

Latest release

A more thoughtful way to make the web yours.

Published November 6, 2026. Now available on the Chrome Web Store with ordered font pairing, a redesigned workspace, and finer control over your everyday reading.

  • A new visual foundation. Inter typography, white and graphite surfaces, cobalt controls, approved brand artwork, and refined light/dark layouts.
  • Ordered font pairing. Primary, secondary and extra fallbacks shared across enabled sites, separate code font, status indicators, and drag or keyboard reordering.
  • A clearer workspace. Fonts, CSS and Library tabs, with a dedicated management page for sites, global CSS, fonts and preferences.
  • More deliberate CSS editing. Separate site/global drafts retained across tabs while the popup stays open; explicit saves, feedback, and full-editor access.
  • Better everyday details. Font-file validation, backup compatibility, refined site controls and corrected right-to-left preview alignment across the five-language interface.
1.2.0Previous release+

Dark mode and more control over everyday reading.

  • Light, dark and system themes; line height, letter spacing, font weight and minimum font size.
  • Subdomain inheritance with per-site opt-out, a site manager, and settings export/import.
  • Global CSS, a font-toggle shortcut, bundled site icons and JetBrains Mono in the CSS editor.
  • Fixes for stale-tab CSS injection and domain boundary cases.
1.1.0The editor update+
  • Replaced the plain textarea with a CodeMirror CSS editor.
  • Removed the Google Fonts API dependency.
1.0.0The first release+
  • Per-site fonts and custom CSS, bundled and Google Fonts support, five interface languages with RTL layouts, auto-enable for all sites, and the original Fabric design.
